# TP Final - API Médiathèque

## Présentation

API REST développée avec FastAPI pour gérer une médiathèque d'albums musicaux.

Un album possède :

- un titre
- un artiste
- un genre
- une année de sortie
- une note sur 10

## Technologies

- Python
- FastAPI
- SQLAlchemy
- SQLite
- Pydantic
- JWT
- Argon2
- Pytest
